# archive/

Retired code, kept for reference. Nothing here is maintained or imported by
`dev/` or `analysis/`.

| Folder | What | Superseded by |
|---|---|---|
| `cli/` | Mac terminal drift monitor (`alert_brainsight_v1.py` … `v2.6.0.py`), `monitor_brainsight.py`, `daq_trigger_out.py` (NI-DAQ test TTL pulses) | `dev/mac_gui/` |
| `analysis/` | Exploratory R scratch (`explore.R`, `multi_target_explore.R`, `sandbox.R`) and stray plots/logs | `analysis/` pipeline + dashboard |
| `build_artifacts/` | Old PyInstaller `.spec` files and `build_intermediate` folders (regenerated by the build scripts) | `dev/*/build/` scripts |

The CLI scripts still run on their own (`python3 archive/cli/alert_brainsight_v2.6.0.py <file>`)
and speak the same wire protocol as the GUI. Archived scripts keep their original
internal path references (e.g. `python/...` in docstrings).
